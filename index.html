NexusPNG v3 structure

Custom binary

Adaptive pipeline

No external libraries
1. Analyze image 2. Detect palette suitability 3. Try palette + bit packing 4. Try palette + RLE 5. Build predictive residuals 6. Select best predictor per row 7. Huffman-code residual bytes 8. Compare every candidate 9. Store smallest valid representation 10. Decode and verify every pixel Fallbacks: RAW → Palette → RLE → Predictive → Huffman The encoder never assumes compression worked. If a compressed representation is larger, NexusPNG stores the smaller representation.
NexusPNG is experimental. Lossless means the decoded pixels are identical, not that every image must become smaller. Information theory remains annoyingly undefeated.
